# Rainy Train

Advanced cinematic train-window rain experience.

## Run
Open `index.html` in a modern browser. For best results use a local server because some browsers restrict local asset/audio behavior.

## Included
- Generated train-window hero image
- Canvas rain particle layer
- Dynamic clock/date
- Journey timer and speed animation
- Journey selector
- Station timeline
- Atmosphere mixer controls
- Night mode
- Fullscreen
- Responsive mobile navigation
- Cinematic scrolling sections
