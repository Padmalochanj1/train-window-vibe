# Rainy Train

Advanced cinematic train-window rain experience.

## Run
Open `index.html` in a modern browser. For best results use a local server because some browsers restrict local asset/audio behavior.

## Included
- Generated train-window hero image
- Canvas rain particle layer
- Dynamic clock/date
- Journey timer and speed animation
- Journey selector
- Station timeline
- Atmosphere mixer controls
- Night mode
- Fullscreen
- Responsive mobile navigation
- Cinematic scrolling sections


## YouTube ambient source
The project is wired to the YouTube URL supplied for this version:
https://www.youtube.com/watch?v=BtlnpBb4O8E&list=RDCLAK5uy_lycab9oGCf-Wrf032tl6Lxn2W68QjdXls

The URL is a YouTube Mix (`RD...`), which is dynamic rather than a fixed `PL...` playlist. The site therefore embeds the exact starting video and provides an **Open on YouTube** link to the live Mix. The Music and Master Volume controls are connected to the embedded player.
